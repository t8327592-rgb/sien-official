# 売上ダッシュボード

`/admin/sales` に追加。直接依頼（個人・法人）・PXstudio・合計を切り替える。既存の売上・経費画面、PXstudioのCSV取り込みは継続して利用する。

## 集計基準

| 基準 | 直接依頼 | PXstudio |
| --- | --- | --- |
| 入金・送金（初期表示） | 有効な入金の実受取額 − 返金。入金日を日本時間で分類 | CSVが「送金済み」の明細の手取り。CSVの送金日で分類 |
| 売上計上日 | 明示された確定金額・売上計上日 | CSV制作費と、管理者が根拠を確認して保存した売上計上日 |

銀行の着金日とCSVの送金日は同一とは限らない。売上計上日を案件作成日・送金日で自動補完しない。売上基準は手取りと混在させない。手数料・源泉徴収は入金基準だけで参考集計し、Expenseへ転記しない。CSVの金額に差額があっても補正・再計算しない。

テスト案件と取消済み入金は除外する。アーカイブ案件も含む。キャンセル案件の実入金・返金は残すが、売上計上基準では除外する。件数は入金・返金・CSVなどの明細数で、案件数ではない。計上日・確定金額未確認、送金未確認の明細は集計外の全期間一覧に分ける。

## 重複確認

氏名・楽曲名の一致、楽曲名と控除前金額の一致、または氏名と控除前金額の一致かつ45日以内の日付を候補として提示する。表記はNFKC・小文字・空白除去で比較する。候補にない組み合わせも手動で選べる。共通の外部IDはないため候補検出は網羅を保証しない。判定は入金基準と売上基準で別々に保存する。

- 未確認・要再確認：関連する直接依頼の明細全体を仮集計から保留。確認待ちの件数・金額を別表示。
- 別取引：双方を集計する。
- 重複：管理者が指定した金額・手数料・源泉徴収だけを直接依頼側から除外し、PXstudio側の金額・日付を残す。元のデータは書き換えない。

部分的な重複や分割入金を許容する。同じ直接依頼に複数候補があるときは、全候補の確認が終わるまで保留する。割当額は直接依頼側・PXstudio側それぞれの各金額上限を超えられない。全額除外すると直接依頼側の明細数からも外れる。返金は自動的に重複除外されないため、元の返金内容を確認する。

「未確認に戻す」で判定を取り消せる。理由・同意を必須にし、変更前後を履歴へ追記する。CSVや対象入金・売上が変わると判定を要再確認にする。PXstudio計上日もCSV変更後は再確認し、再確認した日付で売上基準の重複判定も再確認する。

## データ保護と構成

新規テーブルは `SalesReview`・`SalesPxAccounting`・`SalesReviewAudit` のみ。既存テーブルの列や既存レコードを変更しない。元データへの外部キー・カスケードを追加せず、保存時に有効な対象IDを検証する。対象が無効化・削除された確認情報は集計に採用しない。

確認APIは管理者認証・同一Originを必須とする。CSV取り込みと共通のDBロック、対象依頼の会計ロック、元データのハッシュと確認情報のversionで競合を拒否する。確認結果と履歴を同一トランザクションで保存する。読み取りはRepeatable Readのスナップショットで揃える。

このダッシュボードの除外・保留は、既存画面の合計には反映しない。既存画面は元データ確認用として残る。

## ローカル検証

本番DBや実CSVを利用せず、架空データだけのインメモリPostgreSQLを使う。

```powershell
$env:QA_SALES='1'
node scripts/qa-environment.mjs
# 別ターミナル
node scripts/qa-sales-dashboard.mjs
```

Webは `http://127.0.0.1:3004/admin/sales`、DBは55442、通知はローカルSMTP2527・キャプチャ55443に限定。専用のQA認証情報はqa-environment.mjsに記載。既存QAの3002/55432とは分離する。再実行は環境を再起動し、メモリ上の架空データを作り直す。

結合検証で、直接依頼24,175円＋PXstudio12,500円＝36,675円（2026年入金基準）、部分割当、同時保存、上限超過、日付未確認・年またぎ・基準別判定、既存画面の表示を確認。元のOrder・PaymentRecord・Expense・BusinessContact・PxEntry・取り込み履歴・SiteSettingが確認処理前後で不変であることを照合する。

2026-11-13の検証結果：`npm test` 113件成功、lint・型検査・本番用ビルド成功。ブラウザーで区分切り替え、重複／別取引の保存、計上日の保存と未確認への復帰、320px・390px・1280px幅を確認。日付入力の保持、確認済み除外額0円の再表示も回帰テストで確認。ブラウザーのコンソールエラーなし。私用の検証記録と画像はリポジトリルートの `audit/sales-dashboard-local/` に保存（Git対象外）。
