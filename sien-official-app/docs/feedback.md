# 録音・歌唱フィードバック

## Codexで作る（追加のAI APIを使わない）

1. 管理画面 → 依頼詳細 → フィードバック画面で、気づいたことを順不同でメモ。
2. 「Codex用にメモをコピー」で名前・楽曲名・メモ・比較方法・固定デザインの作成指示をコピー。
3. Codexへ貼り付ける。個人スキル `sien-feedback-pdf` が文章整理からPDF出力まで行う。
4. 出力PDFを確認し、修正があればCodexへ伝える。

管理画面を開かず、Codexへ名前・楽曲名・メモを直接渡しても作成できる。
本サイトはこのフィードバック用にOpenAI・Gemini APIを呼び出さない。
APIキーの登録やAPI残高の購入は不要。

## 固定デザイン

ロゴ・日本語フォント・描画コードを個人スキルに同梱。
A4、白ベース、SIEN.OFFICIALロゴ、オレンジの差し色、見出し・評価欄・余白・フッターを固定する。
デザインは生成のたびにAIが作るのではなく、同じ描画プログラムがデータを流し込む。
`assets/design-lock.json` にコードと資材のハッシュを保持し、変更時は出力を止める。
同じ入力を２回生成してPNG化し、全ページがピクセル単位で一致することを検証。
文章量による折り返し・改ページは自動で調整する。

## 管理画面から手動作成する

文章を直接入力し、下書き保存・内容プレビュー・PDF出力もできる。
PDF出力前に「内容を確認・修正しました」をチェックする。
文章や評価の編集で確認チェックが外れる。
名前・楽曲名は依頼から引き継ぎ、依頼IDや管理メモはPDFに載せない。
初回・比較しない場合は前回比較欄を非表示にする。
比較する場合のみ同じメールアドレスの過去の依頼の直近フィードバックを参考表示する。

## スキル

個人スキル保存先：`~/.codex/skills/sien-feedback-pdf/`
入口：`SKILL.md`、描画：`scripts/render.mjs`、入力例：`references/example.json`。
資材・依存ライブラリは同梱済み。実行時のネット接続・外部AI API・追加npmインストールは不要。

```sh
node <skill>/scripts/render.mjs --input <input.json> --output <report.pdf>
```

同名ファイルを上書きしないため、修正版は別名で保存する。
文章整理は現在のCodexセッションで行う。Codex自体の利用枠はユーザーの契約に従う。

## 検証・リリース

```sh
npm test
npm run lint
npm run build
```

保存データは既存のOrderFeedbackのJSONを利用し、今回の追加DB移行はない。
管理者認証・同一Origin検証・保存バージョンの競合保護は継続する。
