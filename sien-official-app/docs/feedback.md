# フィードバック用メモ

管理画面はメモを入力してCodex用にコピーするための画面です。
評価・コメントの手入力欄、確認チェック、プレビュー、ホームページからのPDF出力はありません。

1. 依頼詳細の「メモを入力・コピー」を開く。
2. 気づいたことを順不同の箇条書きで記入。
3. 初回／前回と比較する／今回は比較しないを選択。
4. 「Codex用にメモをコピー」を押す。名前・楽曲名・メモ・比較方法・固定PDFの作成指示がコピーされ、メモも保存される。
5. Codexのチャットに貼り付け、文章整理と固定PDF作成を依頼する。

コピーが許可されていないブラウザーでは、依頼文を手動コピーできる欄を表示します。
保存エラー時は入力内容を残し、コピーの成否と保存の失敗を分けて表示します。
以前保存した評価文章は消さずに保持します。新しい保存APIはメモ・日付・比較方法だけを更新します。
保存バージョンが競合した場合は409を返し、他の画面のメモを上書きしません。
PDF用GETは廃止し、認証済みでも405となります。PDF作成はCodexの専用スキルへ統一しています。
このフィードバック機能から外部AI APIは呼び出しません。

## 固定PDFスキル

`~/.codex/skills/sien-feedback-pdf/` の個人スキルに、描画コード・ロゴ・フォント・依存ライブラリを同梱。
デザイン資材のハッシュ検証を行い、入力内容だけを差し替えて固定デザインで出力します。
初回の比較セクション・依頼ID・作業メモはPDFに載りません。
サイトのメモからコピーせず、Codexに名前・楽曲名・メモを直接渡しても使えます。

## 検証

```sh
npm test
npm run lint
npm run build
# 隔離DBで保存・画面・PDF機能廃止を検証
node scripts/qa-environment.mjs
# 別ターミナル
node scripts/qa-feedback.mjs
```

追加DB移行はありません。既存のOrderFeedbackのJSONと認証・同一Origin検証を利用します。
